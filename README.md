# 回声 · 1970（Echo 1970）

> 一个以中国科学技术大学为背景的**原创**网页解谜游戏（ARG）。
> 七件档案，八道封印；一个 1965 年留下的声音，一列开往 1970 年的火车，
> 和一本 2026 年在旧书市场用十块钱买到的笔记本。

**在线游玩**：<https://principia-rain.github.io/echo-1970/>

## 玩法

- 打开网页即玩：无需注册、无需下载、无需联网到任何第三方。
- 每件档案藏着一道封印：读文档 → 解谜 → 输入钥匙解封下一件。
- 卡住时点「需要提示」，每道封印有三层递进提示。
- 进度与「给五十年后的留言」只保存在你自己的浏览器（localStorage）。
- 全部故事与谜题均为原创。请勿在公开场合直接贴答案，保护他人体验。

## 技术特色（零依赖）

- **仅一个 `index.html`**：无框架、无构建、无外部字体/图片/请求，双击即可离线游玩。
- 答案以**加盐 SHA-256** 校验（自实现、经 node:crypto 逐例对拍），源码中不出现明文答案。
- 三处「戏外」隐藏层：源代码注释 / 浏览器控制台 / 404 页面——ARG 的传统艺能。
- 响应式排版、打印友好的证书页、`prefers-reduced-motion` 支持。

## 如何把它改造成你自己的 ARG（约 10 分钟）

1. Fork 或复制本仓库。
2. 编辑 `index.html` 中的 `CHAPTERS` 数组：改标题、文档、问题、提示、揭示文本。
3. 为每个封印准备答案，运行：

   ```bash
   node tools/compute_hashes.mjs   # 修改其中 groups 后运行
   ```

   把输出的哈希填回 `HASHES`。注意：`SALT` 与归一化规则（`normAnswer`）
   必须在 `index.html` 与 `tools/` 两处保持一致。
4. 跑一遍测试确认：`node tools/test.mjs`（按你的新答案修改 `expect`）。
5. 换标题、换主题色（CSS 顶部 `:root` 变量），发布到任意静态托管即可。
